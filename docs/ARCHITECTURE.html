3. Component Breakdown

🧩 App.tsx TSX

  • Central state: SimulationState
  • Manages useState + useEffect loop
  • WASM loader via new Function('path', 'return import(path)')
  • Passes translated theory names to ControlPanel
  • 14 theories defined as THEORY_KEY_ORDER
  • JS fallback: stochastic random-walk metrics

🎮 ControlPanel TSX

  • ▶ Start / ⏸ Pause / ↻ Reset buttons
  • Tick counter · Agent count display
  • 14 theory checkboxes (fully translated)
  • Agent slider (10–1000) · Speed selector (4 presets)
  • Export section (JSON / CSV / Summary)
  • Color-coded legend
  • Powered by useTranslation()

🗺️ Simulator TSX Canvas

  • HTML5 Canvas 1000×600 @ up to 500 agents
  • Random-walk physics with polarization clustering
  • Agent colors: red (aggressive) ↔ teal (calm)
  • Influencers (5%) in gold with red outline
  • Network lines between nearby agents
  • HUD overlay: tick, agent count, polarization%, cohesion%
  • requestAnimationFrame loop
  • All labels via t.simulator.*

📊 MetricsDisplay TSX

  • 3 categories: Social · Cultural · Media
  • 11 metric bars with color-coded % values
  • Health indicator: 🟢 Healthy / 🟡 Warning / 🔴 Critical
  • Summary table: Metric · Value · Status
  • Ordered via METRIC_ORDER array
  • All labels via t.metrics.*
